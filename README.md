# M+ Shariah AI - Stock Analysis & Signal Web App

## 1. Free Hosting on GitHub Pages (2 Minutes)
1. Create a free public repository on GitHub (e.g., `mplus-shariah-ai`).
2. Upload all files from this folder (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`).
3. Go to **Settings > Pages**, select **Deploy from a branch** (`main` / `root`), and click **Save**.
4. Your live site will be published at `https://<your-username>.github.io/mplus-shariah-ai/`.

## 2. Install as a Native-Style App on Desktop & Phone
Because this app includes a Web App Manifest (`manifest.json`) and Service Worker (`sw.js`), you can install it directly onto your home screen or desktop:
- **Android (Chrome):** Tap the **Install App** button in the top bar (or `⋮` menu -> **Install app**).
- **iPhone / iPad (Safari):** Tap the **Share** button -> **Add to Home Screen**.
- **Windows / macOS (Chrome / Edge):** Click the **Install App** button in the top bar (or the install icon in the address bar).
